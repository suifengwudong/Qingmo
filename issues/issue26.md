# [功能] 全文搜索支持正则表达式模式

## 描述
高级用户（如技术型作者、编辑）需要用正则表达式进行复杂搜索，例如
匹配所有章节内出现的日期格式、引号内的对话、特定人名的多种写法等。

## 期望行为
- 搜索面板新增"正则"模式勾选框（默认关闭，与"区分大小写"同行）
- 勾选后，搜索框内容作为正则表达式编译（使用标准库 `std::str::pattern` 或手动迭代）
- 正则语法错误时在搜索框下方显示红色错误提示，不崩溃
- 正则模式下"区分大小写"勾选框仍生效（在构建 pattern 时加 `(?i)` flag）

## 实现建议
- 由于不引入新依赖，使用 Rust 标准库的基本字符串匹配；若需要完整正则，
  可引入 `regex` crate（轻量，无不安全代码）先评估 advisory 安全状态
- `search_dir` 签名可扩展为接受 `SearchMode { Literal, Regex }` 枚举
- `TextToolApp` 增加 `search_regex_mode: bool` 字段（默认 `false`）
- `search_regex_error: Option<String>` 字段存储正则编译错误

## 优先级
🟢 低

## 验收标准
- [ ] 输入 `[Aa]lice` 时，正则模式下匹配 "Alice" 和 "alice"
- [ ] 输入 `[` 等非法正则时，UI 显示友好错误提示
- [ ] `search_dir` 正则路径有单元测试（不需要引入 regex crate 也可测基础实现）
